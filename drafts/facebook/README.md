# Facebook page posts

> Standing facts and voice rules: see [PROJECT.md](../../project/PROJECT.md) and [copy-pack.md](../../project/copy-pack.md).

## Timing

**Flexible.** Facebook's algorithm is slow-release like LinkedIn - posts surface over 24-48h. Weekday afternoons (14:00-17:00 Bucharest) slightly better. Weekend posts perform fine for science/education content. **No significant penalty for off-peak posting.**

## Setup

Facebook page needs to be created first (noted in PROJECT.md as pending). Once live, add each post here as a separate file following the naming pattern: `YYYY-MM-DD-short-slug.md`.

## Initial engagement - DO THIS

Facebook's algorithm is engagement-gated like LinkedIn. Early reactions and comments determine reach.

1. **First hour:** All team members (Livia, Newton, Markel) like and comment. Short real comments work best.
2. **Same day:** Ask friends and contacts to like/share. Facebook is the one platform where this is normal and expected - no penalty for asking.
3. **Cross-post from personal profiles:** Each team member shares the page post to their own timeline with a personal take.
4. **Reply to every comment** within a few hours - Facebook rewards conversations.

## Notes

- Facebook penalizes posts with outbound links (suppresses reach ~40-60%). Two strategies: (1) put the link in the first comment instead of the post body, or (2) use native media (image/video) with the link in caption.
- Do not stuff hashtags on Facebook - it restricts reach. Zero to two hashtags maximum.
- Native video gets 5-10x the reach of link posts.
