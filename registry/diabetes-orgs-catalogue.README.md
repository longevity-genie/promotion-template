# diabetes-orgs-catalogue.csv

Partnership and outreach reference for diabetes organizations worldwide.
**Not a posting destination** - these are organizations to contact for study
distribution, grant applications, conference presentations, and recruitment
partnerships.

## Source

Compiled from `temp/diabetes non-profits (1).xlsx` (August 2025 research),
enriched with Sugar-Sugar relevance notes.

## Columns

| Column | Meaning |
|---|---|
| `org_id` | Short stable slug |
| `name` | Organization name |
| `country` | Headquarters / primary operating country |
| `focus` | Diabetes type focus (Type 1, All types, etc.) |
| `size` | Approximate organizational size |
| `grants` | Whether they fund external research |
| `url` | Organization website |
| `sugar_sugar_relevance` | How this org connects to the Sugar-Sugar study |
| `status` | Contact status: `uncontacted`, `contacted`, `partner`, `rejected` |
| `notes` | Free-text |

## Priority tiers for Sugar-Sugar

**Direct fit** (marked in relevance column): Tidepool, Nightscout, OpenAPS,
Beyond Type 1, diaTribe - these communities overlap exactly with the study's
target participants.

**Grant potential**: EFSD, Breakthrough T1D, ADA, DDG, DRWF - organizations
that fund diabetes research and could support study extension.

**Regional recruitment**: diabetesDE (Anton is DE-based), FRDNBM/SRDNBM
(Romanian connection), UDF/IDAU (Ukrainian connection, app has Ukrainian UI).
